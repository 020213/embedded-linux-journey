# embedded-linux-journey

## 目标
2027 年 4 月前具备车载嵌入式 Linux 软件方向的实习能力：C 底层、Linux 系统编程、网络编程、驱动基础。

## 起止时间
2026.11.11 — 2027.04.30，20 周逐日推进。

## 环境
Ubuntu 22.04 / gcc 11.4.0 / gdb 12.1 / git 2.34.1
开发方式：Windows 侧 VS Code + Remote-SSH 连入虚拟机，代码与仓库全部在 Linux 内，Windows 仅作终端。

## 目录
| 目录 | 内容 |
|---|---|
| 00_c | C 语言底层：指针、数组、内存、结构体 |
| 01_env | 编译工具链、Makefile、gdb |
| 02_sys | Linux 系统编程：文件 IO、进程、线程、IPC |
| 03_net | 网络编程：socket、TCP/UDP |
| 04_driver | 驱动基础 |
| 05_project | 综合项目 |
| notes | 每日笔记与周复盘 |
