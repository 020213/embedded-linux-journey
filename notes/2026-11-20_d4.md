# D4 · 2026-11-20 多级指针 + 指针作参数

## 三层传递对照表

| 层级 | 签名 | 副本里装什么 | 能改什么 | 验证文件 |
|---|---|---|---|---|
| 0 | `f(int a)` | int 值 | 什么都改不了 | `1120_swap_value.c` |
| 1 | `f(int *a)` | x 的地址 | x、y 的内容 | `1120_swap_ptr.c` |
| 2 | `f(int **a)` | p1 的地址 | p1、p2 本身 | `1120_swap_pp.c` |

## 三条恒等式

p1 == &x     *p1 == x     pp == &p1
*pp == p1    **pp == x

## 三行笔记

- **它是什么**：跨函数传参永远是副本；副本里装地址就能顺着改原件；想改指针变量本身，必须传指针的地址。
- **用在哪**：链表头插 `insert(Node **head, int v)`；内核出参 `int xxx(struct dev **out)`；`alloc(int **pp)` 返回堆内存。
- **坑在哪**：① 函数里 `p = malloc()` 只改副本，必须 `*pp = malloc()`；② 多写一层 `*`（`**pa = **pb`）就掉进值层面，指针不会换；③ 少写 `&` 报 incompatible pointer types。
